#  Babado News

##  Sobre o projeto

O **Babado News** é um projeto acadêmico desenvolvido durante o curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O projeto consiste na criação de um portal de notícias com foco em informação, entretenimento, esportes, tecnologia, cultura e lifestyle, utilizando tecnologias de desenvolvimento web.

O objetivo é aplicar, na prática, conceitos de **HTML5, CSS3, JavaScript, Bootstrap e Git/GitHub**, desenvolvendo um site responsivo, organizado e de fácil navegação.

---

##  Objetivos

- Desenvolver uma interface de portal de notícias moderno.
- Aplicar conceitos de HTML semântico.
- Criar um layout responsivo.
- Utilizar um framework CSS.
- Implementar navegação entre diferentes páginas.
- Aplicar JavaScript em funcionalidades e interações.
- Utilizar Git e GitHub para versionamento e trabalho em equipe.
- Desenvolver uma experiência de navegação simples e intuitiva.
